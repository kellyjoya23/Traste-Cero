# Traste Cero

Ruta autoguiada para aprender guitarra, desde el nivel 0 hasta el profesional, en 8 niveles.

## Qué incluye

- **Ruta:** 8 niveles con objetivos para marcar, una rutina diaria, ejercicios en tablatura y una prueba para pasar al siguiente nivel.
- **Acordes:** diagramas en cifrado latino (Do, Re, Mi…) con la postura de cada dedo ilustrada y sonido.
- **Práctica diaria:** temporizador por bloques y registro de minutos con racha.
- **Afinador y metrónomo:** notas de referencia, tap tempo y compases 2/4, 3/4, 4/4 y 6/8.
- **Notas del mástil:** juego para aprender qué nota hay en cada cuerda y traste.

El progreso se guarda en el navegador de cada persona (localStorage). No usa servidor ni cuentas.

## Cómo publicarlo

Es una sola página (`index.html`) sin dependencias. Con GitHub Pages:
**Settings → Pages → Deploy from a branch → `main` / root**.
